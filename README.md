# АвтоГид — стартовая страница

Рабочий адаптивный прототип главной страницы федерального сервиса подбора автоинструкторов, созданный по приложенному ТЗ.

## Как запустить в Visual Studio Code

1. Распакуйте архив `AutoGuide.zip`.
2. Откройте в VS Code папку `AutoGuide` через **Файл → Открыть папку**.
3. Откройте терминал VS Code: **Терминал → Создать терминал**.
4. Введите команды:

   ```bash
   npm install
   npm run dev
   ```

5. Перейдите по адресу из терминала, обычно http://localhost:5173/.

**Нужно:** установленный Node.js 20.19+ или 22.12+ (подходит актуальный LTS).

## Уже работает

- Выбор города с сохранением в браузере.
- Поиск по категории и типу коробки передач.
- Фильтрация по цене, имени, наличию подтверждённых документов и сортировка.
- Просмотр демонстрационной карточки инструктора, избранное (в localStorage).
- Адаптивная версия и мобильное меню.

## Важно

Все инструкторы, цены, отзывы, рейтинги и отметки проверки **вымышленные** и предназначены только для демонстрации интерфейса. Вход, связь, SMS, настоящая модерация, серверное хранение и публикация реальных данных пока не реализованы. Без серверной части нельзя считать проверку документов или обработку персональных данных функционирующими.
